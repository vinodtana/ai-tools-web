## 4. Pre-existing deploy-time issues (cannot be fixed by SPA source alone)

1. **HTTP → HTTPS redirect** + **non-www → www redirect** (301 permanent) must be enforced at CDN/hosting layer. Always to `https://www.topaitools.ai`. Cannot be done from robots.txt.
2. **404 handling**: Wildcard route returns React `NotFound.tsx` (returns HTTP 200 because it's a static file). Must configure hosting to return real **404 status code** for unknown paths. Otherwise Google will see many "soft-404"s.
3. **CORS for sitemaps/robots.txt**: No CORS needed (fetched server-side by crawlers).
4. **CDN TTL**: Long-cache `sitemap.xml` only for minutes (1–5 min), not days. Sitemap sub-sitemaps can cache hours/days but regenerate daily in CI.
5. **Security headers**: `Content-Security-Policy`, `X-Content-Type-Options`, `Strict-Transport-Security`, `Referrer-Policy`, `Permissions-Policy` should be set at CDN. Do not block inline JSON-LD (`unsafe-inline` CSP for `script-src` must include `application/ld+json` or hashes; most CDNs support a directive that excludes JSON-LD).
